# Security policy

thonny-ai lets an AI assistant run code on a microcontroller connected to your computer, so its
security model matters. It is described in the README (*Security model*).

## Reporting a vulnerability

Please **do not open a public issue**. Use
[GitHub private vulnerability reporting](https://github.com/AstroQuestStudio/thonny-ai/security/advisories/new)
instead. You will get an answer within a week.

Examples of what we want to hear about:

- any way for a web page, another user on the machine or the network to reach the bridge;
- any way for an AI action to bypass *Approve every AI action* or to hide from the activity log;
- path handling that lets a tool write outside the intended place on the computer.
